# **App Name**: BusWatch

## Core Features:

- Map View: Display real-time bus locations on a map.
- Arrival Times: List upcoming bus arrival times for selected stops.
- Disruption Alerts: AI tool that notifies users of possible service disruptions based on current bus locations and historical data.
- Nearby Stops: Provide a list of the bus stops nearby to the user.
- Favorites: Allow users to save favorite bus routes and stops for quick access.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to evoke a sense of reliability and technology.
- Background color: Light gray (#F0F2F5), a desaturated version of the primary hue, for a clean, modern interface.
- Accent color: Soft purple (#9575CD), an analogous hue, to highlight interactive elements and important information.
- Body and headline font: 'PT Sans' for readability and a modern aesthetic, well-suited for both display and body text
- Use clear and recognizable icons to represent bus stops, routes, and other relevant information.
- Prioritize a clean and intuitive layout with easy navigation and clear information hierarchy.
